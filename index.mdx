## ¿Qué es CommsPlatform?

CommsPlatform es una API unificada para enviar comunicaciones a tus clientes a través de múltiples canales desde una sola integración.

<CardGroup cols={2}>
  <Card title="Email transaccional" icon="envelope">
    Envía emails personalizados con HTML usando plantillas visuales. Postfix + DKIM/SPF/DMARC configurados.
  </Card>
  <Card title="WhatsApp Business" icon="whatsapp">
    Envía templates aprobados por Meta con variables dinámicas vía Meta Cloud API.
  </Card>
  <Card title="Apple Wallet" icon="apple">
    Genera y distribuye pases PKPass firmados digitalmente.
  </Card>
  <Card title="Google Wallet" icon="google">
    Crea objetos de Google Wallet y devuelve un save link listo para compartir.
  </Card>
</CardGroup>

## Cómo funciona

1. **Haces un POST** a `/v1/send/email` (o whatsapp, o wallet) con tu `X-API-Key`
2. **Recibes un `job_id`** — la entrega es asíncrona
3. **Consultas el status** con `GET /v1/jobs/{job_id}` hasta `success` o `failed`

Todo el historial, los cobros y las métricas están disponibles en el dashboard.
