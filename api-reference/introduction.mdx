## Base URL

```
https://comms.panzo.mx
```

## Autenticación

Todos los endpoints `/v1/` requieren el header `X-API-Key` con tu API key de tenant:

```bash
curl https://comms.panzo.mx/v1/send/email \
  -H "X-API-Key: TU_API_KEY" \
  ...
```

Las API keys son emitidas por el operador de la plataforma. Si no tienes la tuya, contáctanos.

## Formato

- Todos los requests son `application/json`
- Todas las respuestas son `application/json`
- Las fechas usan ISO 8601: `2026-03-28T19:21:44Z`

## Códigos de respuesta

| Código | Significado |
|--------|-------------|
| `202` | Job aceptado y en cola |
| `200` | Consulta exitosa |
| `400` | Request inválido — revisa el body |
| `401` | API key inválida o ausente |
| `403` | Canal no habilitado para tu tenant |
| `500` | Error interno del servidor |

## Respuesta de error

```json
{
  "error": "descripción del error"
}
```

## Rate limits

Los rate limits se configuran por tier de plan (free/pro). Si los excedes, recibirás `429 Too Many Requests`.

## Health check

```bash
curl https://comms.panzo.mx/health
```

```json
{"status": "ok"}
```

No requiere autenticación.
